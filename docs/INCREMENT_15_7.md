# Incremento 15.7 — Integration Operations UI

Transforma o console técnico Microsoft em uma central operacional para o professor.

## Painel operacional

Mostra status da conexão, turmas vinculadas, cobertura de alunos, atividades mapeadas,
entregas importadas e a próxima ação recomendada.

Prioridade:

```text
Conexão → Turmas → Alunos → Atividades → Entregas → Em dia
```

Os atalhos levam diretamente para Turmas, Alunos, Atividades e Entregas.

A lógica existente de integração permanece intacta; esta fatia altera somente a experiência operacional.

## Google Classroom

Permanece em standby na UI. A fundação já existente não é removida, mas não participa do fluxo operacional principal.
